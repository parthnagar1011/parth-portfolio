AI Crop Disease Detection

CropCure is a web-based system that classifies crop diseases from images and suggests treatment, built to help farmers act before a problem spreads. This became the project I later carried into the Smart India Hackathon.

I trained the classification models and built the real-time analysis flow that plugs into the web app.

Deepfake Detection System — TruthLens

TruthLens is a deep-learning model that flags manipulated media, paired with a straightforward interface so a non-technical user can upload a file and get a clear read on whether it's real.

Focused on classification accuracy first, then on making the result legible — a report, not just a probability.
